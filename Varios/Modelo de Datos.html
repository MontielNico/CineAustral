Podés hacer clic en cada fase para expandirla o colapsarla. Algunas aclaraciones importantes sobre las decisiones del roadmap:

¿Por qué empezar por el setup antes que por la lógica? Muchos proyectos se traban al final cuando intentan integrar las partes. Si desde el día 1 tenés React hablando con Spring Boot y Spring Boot hablando con PostgreSQL, vas a detectar problemas de configuración temprano.

¿Por qué JWT en la fase 2 antes de cualquier pantalla? Porque si construís todas las pantallas sin seguridad y después intentás agregar JWT, tenés que refactorizar todo. Es mucho más limpio tenerlo desde el inicio.

¿Por qué React al final? No exactamente — React va en paralelo con el backend en cada fase. Pero dentro de cada fase, conviene terminar el endpoint antes de la pantalla, así React siempre tiene datos reales con los que trabajar.

La grilla de asientos (Fase 4) va a ser la parte más desafiante del frontend. Es la pantalla más visual e interactiva del sistema. Cuando lleguemos ahí te ayudo con ese componente específicamente.

Paso 1 — Crear el proyecto en Spring Initializr

Entrá a start.spring.io y configurá así:

  • Project: Maven
  • Language: Java
  • Spring Boot: 3.4.x (la última estable)
  • Group: com.cineaustral
  • Artifact: backend
  • Packaging: Jar
  • Java: 21

Dependencias a agregar:

  • Spring Web
  • Spring Data JPA
  • Spring Security
  • PostgreSQL Driver
  • Lombok

Descargás el ZIP, lo descomprimís y lo abrís en tu IDE (IntelliJ recomendado).

Paso 2 — Estructura de carpetas

Una vez abierto el proyecto, creá esta estructura de paquetes dentro de com.cineaustral.backend:

com.cineaustral.backend/
├── config/          ← configuración de seguridad, CORS, beans
├── controller/      ← endpoints REST
├── dto/             ← objetos de transferencia de datos
├── entity/          ← entidades JPA
├── enums/           ← estados (AsientoEstado, SalaEstado, etc.)
├── repository/      ← interfaces JPA
└── service/         ← lógica de negocio

// entity/Usuario.java
package com.cineaustral.backend.entity;

import com.cineaustral.backend.enums.UsuarioRol;
import jakarta.persistence.*;
import lombok.*;

@Entity
@Table(name = "usuarios")
@Getter @Setter @NoArgsConstructor @AllArgsConstructor @Builder
public class Usuario {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String nombre;

    @Column(nullable = false, unique = true)
    private String email;

    @Column(nullable = false)
    private String password;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private UsuarioRol rol;
}

// entity/Sala.java
package com.cineaustral.backend.entity;

import com.cineaustral.backend.enums.SalaEstado;
import jakarta.persistence.*;
import lombok.*;

@Entity
@Table(name = "salas")
@Getter @Setter @NoArgsConstructor @AllArgsConstructor @Builder
public class Sala {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String nombre;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private SalaEstado estado;

    @OneToMany(mappedBy = "sala", cascade = CascadeType.ALL, orphanRemoval = true)
    private java.util.List<Asiento> asientos = new java.util.ArrayList<>();
}
java
// entity/Asiento.java
package com.cineaustral.backend.entity;

import com.cineaustral.backend.enums.AsientoEstado;
import jakarta.persistence.*;
import lombok.*;

@Entity
@Table(name = "asientos")
@Getter @Setter @NoArgsConstructor @AllArgsConstructor @Builder
public class Asiento {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String fila;

    @Column(nullable = false)
    private int numero;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private AsientoEstado estado;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "sala_id", nullable = false)
    private Sala sala;
}
java
// entity/Funcion.java
package com.cineaustral.backend.entity;

import jakarta.persistence.*;
import lombok.*;
import java.time.LocalDateTime;

@Entity
@Table(name = "funciones")
@Getter @Setter @NoArgsConstructor @AllArgsConstructor @Builder
public class Funcion {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private LocalDateTime fechaHora;

    @Column(nullable = false)
    private int duracionMinutos;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "pelicula_id", nullable = false)
    private Pelicula pelicula;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "sala_id", nullable = false)
    private Sala sala;
}
java
// entity/Reserva.java
package com.cineaustral.backend.entity;

import jakarta.persistence.*;
import lombok.*;
import java.time.LocalDate;

@Entity
@Table(name = "reservas")
@Getter @Setter @NoArgsConstructor @AllArgsConstructor @Builder
public class Reserva {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private LocalDate fechaReserva;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "funcion_id", nullable = false)
    private Funcion funcion;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "asiento_id", nullable = false)
    private Asiento asiento;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "cliente_id", nullable = false)
    private Usuario cliente;
}

Con esto hecho, levantá el proyecto. Si todo está bien configurado, Hibernate va a crear las tablas automáticamente en PostgreSQL. Deberías ver en la consola algo como:

Hibernate: create table usuarios (...)

Si ves eso, la Fase 1 del backend está completa. Si aparece algún error, pegalo acá y lo resolvemos.

Un par de cosas para tener en cuenta mientras codés:

fetch = FetchType.LAZY en todos los @ManyToOne es importante para evitar que Hibernate traiga datos innecesarios en cada consulta. Y usamos @Enumerated(EnumType.STRING) para que en la base de datos los estados se guarden como texto ("LIBRE", "OCUPADO") en vez de números, lo que hace la base mucho más legible.
